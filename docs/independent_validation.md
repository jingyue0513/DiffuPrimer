# 独立实验准备

当前没有本研究候选的独立 qPCR 实验结果。`results/lab_plan/` 只保存实验准备材料；填写前的表格不能进入成功率、效率或显著性计算。

40 个基因从冻结测试集独立随机抽取，不按模型可设计性挑选。它们全部不参与模型训练。每个基因拟比较 Primer3 与扩散模型各两个候选，排序规则为通过相同计算与 RNA 筛查后按共同温度评分排序并去重。没有设计出的槽位保留为 `no_design`，不得删去该基因。

`prepare_lab_plan.py` 生成基因选择文件、方法隐藏的候选编号、单独的解盲对照表、三次技术重复及 NTC/noRT 的空记录模板。模板默认 96 孔板，仅供资源评估；真实板型、板间安排、材料、仪器与实验条件需由实验室确定。解盲文件不得提前交给负责判读实验结果的人。

在实验前需要固定材料来源、RNA 质量标准、逆转录流程、试剂与仪器设置、实验成功判据、重复性与效率评价方法，以及低表达或样本缺失的失败分类。当前阈值文件保留 `null` 并标为未冻结，程序不会将空白值解读为通过。

最终记录应包括原始扩增和熔解文件、预期大小与产物身份检查、必要对照、浓度/标准曲线资料、重复性、全部失败与未设计目标。标准曲线效率可按 `E = 10^(-1/slope) - 1` 计算，但应记录拟合区间和原始输入量，避免把估计值当成每个反应的固定效率。

按 [MIQE 2.0](https://doi.org/10.1093/clinchem/hvaf043) 整理报告信息。材料使用、机构审批、作者贡献与实际实验数据由研究团队提供。公开数据库历史实验不属于本模型新候选的独立验证。
